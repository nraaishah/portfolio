# Software projects

Two projects that combine user-facing design with backend systems and real data.

## PulsePath AI · Accessible walking routes

A mobile app for residents of City of Elmina, Selangor. It uses an OpenStreetMap pedestrian network to help users compare a shorter walk with a route tailored to their accessibility preferences.

- Search for a destination such as Elmina Valley Central Park and compare the Shortest and Accessible routes.
- Open the map and follow the route directions.
- Record a barrier at a location and review it in My Reports.

[Try the PulsePath AI live demo](https://pulsepath-ai-demo.onrender.com/)

**Stack:** Expo, React Native, TypeScript, Node.js, Leaflet, OpenStreetMap.

## ValueSense · Explainable Malaysian house price prediction

A final-year project that estimates residential property prices in Malaysia and shows which factors influenced each estimate.

- Enter property details and review the estimated price and its SHAP explanations.
- Explore price patterns by location and compare similar properties.
- Export an estimate as a PDF or JSON report.

[Try the ValueSense live demo](https://valuesense-demo.onrender.com/predict)

**Stack:** React, Vite, Python, FastAPI, scikit-learn, SHAP.
